# ALEN CUP 제출 초안 — CodePup

## 작품 이름
**CodePup (코드펍) — Claude Code 세션을 대신 지켜보는 데스크톱 펫** (macOS)

## 누구의 어떤 불편을 해결했나요? (문제 이해)
Claude Code 에게 일을 맡기면, 개발자는 **기다리는 사람**이 돼요. 세션을 두세 개 띄워 두고 다른 창을 보다 보면
- **허락 요청(y/n)에 멈춘 세션을 모르고 10분씩 방치**해요. Claude 는 한 줄 대답만 기다리고 있었는데요.
- 끝났는지 확인하려고 **터미널 탭을 계속 돌아다녀요.**
- 밖에서 휴대폰으로 원격 작업을 이어 가려는데 **맥이 잠들어서** 세션이 멈춰 있어요.
- 터미널을 닫았다가 원격 제어 세션들을 되살리려면 `claude --resume <id>` 를 **하나하나 다시 입력**해야 해요.

제가 매일 겪던 불편이에요. 핵심은 하나예요: **"Claude 가 나를 기다리는데, 나는 모른다."**

## 어떻게 해결했나요? (해결의 효용)
화면 구석을 걸어 다니는 작은 치와와가 모든 세션을 대신 지켜봐요.
- **그 자리에서 허락**: 허락이 필요하면 펫이 달려와서 말풍선에 **[허락] [거절]** 을 띄워요. 터미널로 가지 않아도 세션이 바로 진행돼요.
- **작업 끝 알림**: 끝나면 "✅ api-server 작업 끝!" 과 답변 첫 문장을 알려 줘요. 평소엔 조용하고, **소리가 나면 = 나를 부르는 것**이에요.
- **메뉴 막대 팝오버**: 아이콘을 누르면 허락 대기 카드, 세션 목록, CPU · 메모리 · 저장공간 · 배터리를 한 화면에서 봐요.
- **세션 보드(⌥⌘J, 바꿀 수 있어요)**: 세션이 10개여도 기다리는 것만 크게, 나머지는 한 줄씩. 펼치면 답변이 마크다운으로 깔끔하게 보여요.
- **☕ 잠자기 방지**: 세션이 열려 있는 동안 맥이 잠들지 않아요. 외출할 땐 "덮개를 닫아도 잠들지 않기" 한 번.
- **닫힌 세션 골라서 다시 열기**: 터미널이 닫혀 사라진 세션만 골라 쓰던 창에 탭으로 복구해요. 원래 권한 모드와 원격 제어(--rc) 그대로. `/exit` 로 직접 끝낸 세션은 되살리지 않아요.
- **이미 열려 있던 세션도**: 앱을 켜기 전부터 돌던 claude 도 찾아내고, [🔔 알림 켜기] 한 번이면 같은 탭에서 이어서 다시 열어 알림을 받게 해 줘요.

기다리던 시간이 **"알림 → 클릭 한 번"** 으로 줄어요.

## 사용 편의성
- 처음 켤 때 [Claude Code 연결] 버튼 하나면 끝이에요. 설정 파일을 직접 고칠 필요가 없어요.
- Claude Code **공식 훅**만 써요. API 를 부르지 않고, 로그인 정보를 만지지 않고, 모든 통신은 내 컴퓨터 안(127.0.0.1)에서만 해요.
- 기존 설정은 그대로 두고 처음 한 번 백업을 남겨요. 쓰던 상태 표시줄(claude-hud 등)도 그대로예요. 앱이 꺼져 있으면 Claude Code 에 아무 영향이 없어요.
- 권한은 절대 자동으로 허락하지 않아요. 펫에서 답이 없으면 원래대로 터미널에서 물어봐요.
- 메뉴 막대 앱이라 Dock 을 차지하지 않고, 펫 밖의 클릭은 뒤의 앱으로 그대로 전달돼요.

## 덤: 계속 켜 두고 싶게 만드는 재미
- 쓰다듬기, 들어서 던지기, 밥 주기, 낮잠, 레벨 업 같은 다마고치 요소. 세션이 작업을 끝낼 때마다 펫도 함께 성장해요.
- RunCat 처럼 CPU 가 바쁘면 빨리 달리는 메뉴 막대 아이콘.
- 스킨 시스템: 기본 치와와 '초코' + 스피키 스킨(작업이 끝나면 "쪼아요~ 쪼아요~"), 내 캐릭터 폴더도 불러올 수 있어요.

## 이번 기간에 제작 · 개선한 내용
- 기존 작품: 웹 브라우저에서만 동작하던 캐릭터 드래그 놀이 페이지 (madirony/speaki-simulator)
- 이번 기간에 새로 만든 것:
  1. Electron 기반 macOS 데스크톱 앱 (투명 오버레이, 클릭 통과, 메뉴 막대 팝오버 · 시스템 모니터, 다마고치)
  2. Claude Code 연동 (로컬 브리지 + 훅 원클릭 설치, 허락/거절 말풍선, 작업 끝 알림, 세션 보드, 실행 중인 세션 찾기, 골라서 복구, 잠자기 방지)
  3. 저작권 문제가 없는 오리지널 기본 캐릭터(블랙탄 치와와, 표정 20종)와 WebAudio 옹알이 목소리, 스킨 시스템
  4. 단위 테스트 41개 + 실제 훅 스크립트를 쓰는 전체 흐름 스모크 테스트 32개, GitHub Actions 로 dmg 자동 빌드 · 릴리스

## 작품 확인 자료 (60초 데모 영상 콘티)
| 시간 | 화면 | 자막 |
| --- | --- | --- |
| 0–5초 | 터미널 탭 3개에서 claude 실행, 화면 구석에 치와와가 걸어 다님 | "세션 여러 개 돌려 놓고… 다른 일 하는 중" |
| 5–15초 | 브라우저를 보는 중에 치와와가 달려와 "🔔 api-server: npm install 해도 돼요?" → [허락] | "허락 요청? 터미널 안 가도 돼요" |
| 15–25초 | "✅ web-front 작업 끝!" 말풍선 + 소리 | "끝나면 달려와서 알려 줘요" |
| 25–35초 | 메뉴 막대 아이콘 클릭 → 팝오버 (허락 카드 · 세션 목록 · 시스템) | "메뉴 막대만 눌러도 내 Claude 들이 한눈에" |
| 35–42초 | ⌥⌘J 세션 보드: 한 줄씩, 하나 펼치면 답변이 마크다운으로 | "세션이 많아도 한눈에" |
| 42–52초 | 터미널 창을 닫음 → 팝오버 [🔁 닫힌 세션] → 2개만 골라 열기 → 탭으로 다시 열림 | "닫은 세션도 골라서 한 번에 (원격 제어 · 권한 모드 그대로)" |
| 52–60초 | 치와와를 쓰다듬고 휙 던지면 어지러워함 | "기다리는 시간이 조금 더 즐거워지도록" |
