# ALEN CUP 제출 초안 — CodePup

## 작품 이름
**CodePup (코드펍) — Claude Code 세션을 대신 지켜보는 데스크톱 펫** (macOS)

## 누구의 어떤 불편을 해결했나요? (문제 이해)
AI 코딩 에이전트(Claude Code)로 일하는 개발자는 세션을 여러 개 띄워 두고 기다리는 시간이 많아요. 그런데
- 세션이 **끝났는지** 확인하려고 터미널 탭을 계속 돌아다니고,
- **권한 요청(y/n)** 에서 멈춘 걸 모르고 다른 창을 보다가 몇 분씩 그냥 흘려보내고,
- 긴 작업을 맡기고 나갔는데 맥이 잠들어서 작업이 멈춰 있거나, 밖에서 원격으로 이어서 하려는데 맥이 꺼져 있고,
- 자리를 비우면 세션도 같이 멈추고,
- 한 세션의 결과를 다른 세션에 알려 주려면 복사·붙여넣기를 해야 하고,
- 터미널을 닫았다가 원격 제어 세션을 다시 열려면 `claude --resume` 을 하나하나 입력해야 했어요.

"작은 알림 하나 놓쳐서 흐름이 끊기는 것", 매일 반복되는 이 귀찮음을 없애고 싶었어요.

## 어떻게 해결했나요? (해결의 효용)
화면 구석을 걸어 다니는 작은 치와와가 모든 세션을 대신 지켜봐요.
- **작업 끝 알림**: 세션이 끝나면 달려와서 "✅ api-server 작업 끝!"과 결과 요약을 말풍선으로 알려 줘요.
- **그 자리에서 허락**: 권한 요청이 오면 말풍선에 [허락] [거절] 버튼이 떠요. 터미널로 가지 않아도 세션이 바로 진행돼요. 기다리는 세션 수는 빨간 배지로 보여요.
- **☕ 잠자기 방지**: Claude 세션이 열려 있는 동안 맥이 잠들지 않아요. 외출할 땐 "덮개 닫아도 안 잠들기" 한 번이면 밖에서 원격으로 계속 작업할 수 있어요.
- **세션 보드(⌘⇧J)**: 여러 세션의 상태·하는 일·마지막 답변을 한 화면에서 보고, [터미널로 이동]으로 해당 탭을 바로 앞으로 가져와요.
- **닫힌 세션 다시 열기**: 터미널이 꺼져서 사라진 세션만 골라 한 번에 새 터미널로 복구해요. /exit 로 직접 끝낸 세션은 되살리지 않아요. 원격 제어(--rc)도 켠 채로 열려요.

기다리는 동안 놓치던 시간이 "알림 → 클릭 한 번"으로 줄어요.

## 사용 편의성
- 설치 후 처음 켤 때 [Claude Code 연결] 버튼 하나면 끝이에요. 설정 파일을 직접 고칠 필요가 없어요.
- 기존 설정은 건드리지 않고 백업을 남겨요. 앱이 꺼져 있으면 Claude Code 에 아무 영향이 없어요.
- 권한은 절대 자동으로 허락하지 않고, 펫에서 답이 없으면 원래 터미널 창으로 넘어가요.
- 메뉴 막대 앱이라 Dock 을 차지하지 않고, 펫 밖의 클릭은 뒤의 앱으로 그대로 전달돼요.

## 덤: 계속 켜 두고 싶게 만드는 재미
- 쓰다듬기, 들어서 던지기, 밥 주기, 낮잠, 레벨 업 같은 다마고치 요소가 있어요. 세션이 작업을 끝낼 때마다 펫도 함께 성장해요.
- RunCat 처럼 CPU 사용률에 맞춰 달리는 메뉴 막대 아이콘과 CPU · 메모리 · 저장공간 · 배터리 표시가 있어요.
- 스킨 시스템으로 내 캐릭터 이미지와 목소리를 폴더째 불러올 수 있어요.

## 이번 기간에 제작 · 개선한 내용
- 기존 작품: 웹 브라우저에서만 동작하던 캐릭터 드래그 놀이 페이지 (madirony/speaki-simulator)
- 이번 기간에 새로 만든 것:
  1. Electron 기반 macOS 데스크톱 앱 (투명 오버레이, 클릭 통과, 메뉴 막대 시스템 모니터, 다마고치)
  2. Claude Code 연동 (로컬 브리지 + 훅 원클릭 설치, 알림 말풍선, 허락/거절, 세션 보드, 세션 복구)
  3. 저작권 문제가 없는 오리지널 기본 캐릭터(블랙탄 치와와, 표정 20종)와 WebAudio 옹알이 목소리, 스킨 시스템
  4. 단위 테스트 24개와 실제 훅 스크립트를 쓰는 전체 흐름 스모크 테스트 21개, GitHub Actions dmg 빌드

## 작품 확인 자료 (60초 데모 영상 콘티)
| 시간 | 화면 | 자막 |
| --- | --- | --- |
| 0–5초 | 터미널 3개에서 claude 실행, 화면 구석에 치와와가 걸어 다님 | "세션 여러 개 돌려 놓고… 다른 일 하는 중" |
| 5–15초 | 브라우저를 보고 있는데 치와와가 뛰어오르며 "🔔 api-server: npm install 해도 돼요?" [허락] 클릭 | "허락 요청? 터미널 안 가도 돼요" |
| 15–25초 | "✅ web-front 작업 끝!" 말풍선 → [보드] 클릭 → 세션 보드 | "끝나면 달려와서 알려 줘요" |
| 25–35초 | 세션 보드(⌘⇧J): 세션 10개가 한 줄씩, 하나 펼치면 답변이 마크다운으로 | "세션이 많아도 한눈에" |
| 42–50초 | 터미널 창을 다 닫음 → 메뉴 막대 [닫힌 세션 다시 열기] → 창이 다시 열림 | "닫은 세션도 한 번에 복구 (원격 제어 포함)" |
| 50–60초 | 치와와를 쓰다듬고 휙 던지면 어지러워함, 메뉴 막대 CPU 아이콘 | "기다리는 시간이 조금 더 즐거워지도록" |
