Claude Code 연결

⚪ 연결 안 됨

연결하면 에 알림용 훅을 추가해요. 기존 설정은 그대로 두고 백업을 남겨요. 이미 열려 있던 세션은 다시 시작해야 적용돼요.

☕ 잠자기 방지

언제

노트북 덮개를 닫으면 macOS 는 잠자기 방지 앱이 있어도 잠들어요. 외출할 때는 메뉴 막대의 🧳 덮개 닫아도 안 잠들기를 켜 주세요 (관리자 암호를 한 번 물어봐요).

알림 · 응답

켜 두면 세션이 끝났을 때 터미널 대신 세션 보드에서 바로 다음 지시를 보낼 수 있어요. 기다리는 동안 그 터미널은 입력을 받지 않으니, 자리로 돌아오면 끄거나 [터미널에서 할게요]를 눌러 주세요.

🔁 닫힌 세션 다시 열기

메뉴 막대나 세션 보드에서 닫힌 세션을 한 번에 다시 열어요. (claude --resume)

⚠️ 건너뛰면 Claude 가 파일 수정 · 명령 실행을 묻지 않고 바로 해요. 믿을 수 있는 프로젝트에서만 켜 주세요. 이렇게 연 세션은 허락 말풍선이 뜨지 않아요.

macOS 터미널은 탭을 만들 때 ⌘T 를 보내서, 처음 한 번 손쉬운 사용 권한을 물어봐요. 허용하지 않으면 새 창으로 열려요. iTerm2 는 권한 없이 탭으로 열려요.

움직임

RunCat처럼 메뉴 막대 아이콘의 펫이 CPU 사용률에 맞춰 달려요. 옆에 표시할 항목을 고르세요.

스킨

표정 · 소리를 한 번에 바꾸는 캐릭터 팩이에요. skin.json 이나 default.png 가 들어 있는 폴더를 불러올 수 있어요.

표정 하나씩 바꾸기

기본 이미지만 바꿔도 나머지 표정이 모두 그 이미지로 바뀌어요. 배경이 투명한 PNG를 추천해요.

소리

CodePup

여러 Claude Code 세션을 대신 지켜보다가, 끝나거나 허락이 필요하면 달려와서 알려 주는 데스크톱 펫이에요. 메뉴 막대에서는 CPU · 메모리 · 저장공간 · 배터리도 보여 줘요.

기본 캐릭터 '블랙탄 치와와'는 이 앱을 위해 새로 그린 오리지널 캐릭터예요. 스킨 폴더를 불러와 원하는 캐릭터로 바꿀 수 있어요. 스피키 스킨: 트릭컬 / Trickcal — 비상업적 팬 메이드.
